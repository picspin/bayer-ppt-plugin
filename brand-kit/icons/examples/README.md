# Icon language exemplars (outline only)

Generic radiology-style **outline** SVG exemplars (256×256, Dark Blue `#10384F`, stroke-width ≈ 8).

These are style references for agents — not a complete Icon Library and **not** product lockups.

| File | Motif |
|------|--------|
| `confidence-outline.svg` | Confidence pillar |
| `heart-outline.svg` | Heart (indications) |
| `lungs-outline.svg` | Lungs |
| `liver-outline.svg` | Liver |
| `kidneys-outline.svg` | Kidneys |
| `person-outline.svg` | Person / patient |
| `magnifier-outline.svg` | Magnifying glass (objects) |

Full SVG/PNG/WMF media and product logos live in the proprietary Icon Library POTX — drop that into `brand-assets/source/icon-language.potx` (see repo README). Do **not** commit product lockup PNGs/WMF into this package.
